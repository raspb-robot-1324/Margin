Recherche — jeux & apps similaires

01.2

Point de départ : studyquest.app/games (40+ modes type arcade sur le contenu scolaire). Ci-dessous : ce que j’ai trouvé + suggestions à explorer.

Produit Ce qu’ils font Écart vs Study Rink Proximité
StudyQuest
 Upload notes → IA → quiz / flashcards branchés sur des mini-jeux (Boss Battle, Snake, Subway Surfers, Study Siege, Knowledge Factory…). XP, streaks, plans d’étude. Le « jeu » est une peau sur les questions. Pas de carrière persistante, pas de lien organisation scolaire ↔ compétition sport. À regarder : variété des modes, friction d’entrée, feel des streaks. Proche
CRAMMIT
 Génération quiz/cartes depuis fichiers + modes de rétention + arènes multi (Classic Arena, CyberHeist). Très fort sur création de contenu + social. Study Rink = solo / carrière longue, pas live class. Proche
FlashQuest Arena
 Batailles flashcards temps réel (code room, même question, vitesse + exactitude). Inspire l’idée « chaque réponse compte » — déjà dans notre arène d’examen. Pas de meta-progression hors du duel. Adjacent
Habitica
 Vie réelle → RPG (XP, stuff, HP si on skip). Pixel, parties, boss via tâches. Même famille « productivité gamifiée », mais tâches génériques ≠ SRS / devoirs / examens. À piquer : clarté des récompenses, punition douce vs notre « décrochage sans punition ». Adjacent
Forest / Focus Friend
 Focus timer → récompense visuelle (arbre / bean). Anti-distraction. Un seul pilier (tenir). Chez nous : micro-départ 2 min + forme du jour qui bloque les matchs BOSS. Adjacent
Quizlet / Kahoot!
 Cartes + Live / quiz classe. Standards du marché scolaire. Référence UX flashcards / pression sociale. Aucune boucle carrière. Benchmark import Anki / friction. Réf.
Duolingo
 Leçons courtes, streaks, XP, mascotte culpabilisante, leaderboards. Gold standard addiction / micro-sessions. Domaine fixe (langues). Étudier leur onboarding + plafond quotidien. Réf.
Stackd / Qardex
 Upload → cartes / quiz / mini-jeux compétitifs ; courses de decks entre amis. Vague « notes → jeu » saturée. Renforce notre différenciateur : hockey + forme + organisation, pas juste arcade quiz. Vague

Notre angle (à défendre)

Pas « encore un skin de quiz ». Une carrière de hockey alimentée par l’étude réelle (SRS, devoirs, focus), avec une règle unique : tout crédite le même entonnoir (CareerLedger).

Ce que StudyQuest fait mieux (pour l’instant)

Entrée contenu ultra large (PDF → 40 jeux). À noter pour plus tard : génération IA de cartes (L6 prévu), sans diluer la boucle hockey.

Piège à éviter

Empiler des mini-jeux décoratifs. Chaque surface d’étude doit bouger forme / XP / contrat — sinon on rejoint le pack « arcade quiz ».

À tester cette période

1 session StudyQuest (Boss Battle + Study Café) · 1 run Habitica · regarder Forest / Focus Friend pour le feel du micro-focus · capturer QuizLearn Live si accessible.

Notes télégraphiques — features à (ré)affirmer

01.3

Beaucoup est déjà ✅ dans le build. Ci-dessous : ce que je mets en avant pour le mentor + ce qui reste.

  • Boucle unique : étude → EP → XP attributs + forme + $ + phase carrière + contrat du jour
  • SubjectMap : matière scolaire → attribut hockey (mental / patinage / charisme…)
  • Focus : micro-départ 2 min (meilleur tarif EP) · reprise après décrochage · pas de punition si honnête
  • Organisation : devoirs + agenda 14 j · retard = pression sur la forme
  • Apprendre : SRS (fuzzing, sangsues) · import Anki · cram à taux réduit · coaching sujets faibles
  • Hockey : hub pixel · matchs 2D / simu · boss division · junior → draft → pro · coach / GM
  • Arène examens : chaque réponse = rappel crédité, même en défaite / abandon
  • Plafonds : régularité > acharnement (EP dégressifs après plafond souple)
  • Suite : L6 génération cartes/quiz IA · polish art · (hors scope : multi, Screen Time, autres sports)

Style général du jeu

01.4

Direction

  • Genre : compagnon d’étude × sim carrière hockey
  • Vue : 2D pixel, hub lisible (patinoire / vestiaire / maison)
  • Ton UI : français, direct, reçus de récompense partout (CareerToast)
  • Feel : sérieux sur l’étude, fun sur le hockey — pas cartoon-culpabilisant type Duo
  • Art : placeholder pixel remplaçable · priorité lisibilité > effets
  • Audio : bus simple · pas de bruitage agressif pendant focus
Encre
Glace
Rink
Ligne
  • Réfs visuelles à noter : Habitica (pixel RPG clair) · NHL scorebug (info dense) · Animal Crossing hub (mais plus « vestiaire »)
  • Anti-réfs : casino UI · glow néon · overload de badges à chaque clic
  • Plateformes : macOS d’abord → iOS
  • Sauvegarde : locale JSON maintenant · Supabase plus tard (hors scope immédiat)
